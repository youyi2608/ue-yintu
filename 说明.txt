【小番茄（TomatoScramble）解码】
小番茄是同一套吉尔伯特曲线 + 黄金比例位移，但有三点不同：
  · 不补边（解出来尺寸不变）
  · 没有色块条（底部那条红/蓝色块）
  · 它的"密码"是一个数（默认 1），不是四位数字
现在的规则：
  · 图底部有色块条 → 走大番茄 V3（和以前一样）
  · 没有色块条 → 大番茄 V2 和小番茄两条都试，取"解码后更平滑"的那个
  · 两条都不过阈值 → 照旧提示"不是混淆图 / 解不出来"
  · 高级选项里那行「小番茄密钥」只在这条路上用；默认 1，可用 − / + 调（0.1~9）
  · 混淆（加密）方向暂时没给入口，代码里已经写好
✔ **已用真机样本逐像素验证一致**：拿小番茄 App 直接导出的 896×1152 原图，
   先解码、再用本程序重新混淆，与 App 那张原图逐像素比对 **0 差异**（1032192 个像素全同）。
   所以小番茄这条路不是"看起来对"，是和 App 的算法完全一致。

【PicEncrypt / 小番茄 的 6 种混淆方式】
现在都能解码，默认「自动」——按顺序把每种模式 × 几种常见 key 都试一遍，
取"解出来最平滑"的那个，过阈值才算认出来。认不出来就在「高级选项 → 混淆方式」手动指定。

1) 小番茄（TomatoScramble）
   吉尔伯特曲线 + 黄金比例位移；不补边、没有色块条。
   参数：key 是一个数，默认 1（App 里 defaultTomatoKey = 1，范围 0~1.618）。

2) 块混淆（BlockScramble）
   先把画布补到 32 的倍数，再把 32×32 个块按 key 打乱。
   参数：key 是**字符串**，App 默认 "0.666"；块大小写死 32×32，没有设置项。
   注意：补过边，解出来的画布是补边后的尺寸（例如 400×300 → 416×320），原图在左上角。

3) 行像素混淆（RowPixelScramble）
   每一行内部按 key 打乱列的位置。参数：key 是字符串，默认 "0.666"。

4) 逐像素混淆（PerPixelScramble）
   每个像素单独打乱（列和行都打乱）。参数：key 是字符串，默认 "0.666"。

5) 兼容 PicEncrypt：行模式（PicEncryptRowScramble）
   用 logistic 混沌映射（x←3.9999999·x·(1-x)）生成列顺序，逐行重排。
   参数：key 是**小数**，默认 0.666，范围 0~1。

6) 兼容 PicEncrypt：行+列模式（PicEncryptRowColumnScramble）
   先按行打乱列、再按列打乱行，key 沿行列链式递进。参数同 5)。

【哪些"没密码也能解"、哪些"必须知道密钥"】
  · 这 6 种在 App 里都有默认 key：小番茄是 1，其余 5 种是 0.666。
  · 所以：**用户没改过 key** → 自动模式能认出来，不需要你填。
  · **用户改过 key** → 必须知道那个 key；自动模式只会试 0.666 / 1 / 0.5 / 2 / "" / 123 这几个常见值，
    试不出来就会提示"不是混淆图，或者需要别的密钥 / 模式"，这时手动选模式 + 说明 key 才有用。
  · 块混淆的块大小是写死的 32×32（源码里没有设置项），不需要也不允许改。
  · 只有"小番茄"这条路已经用真机样本逐像素验证过；其余 5 种是照源码实现的，
    往返自测（encode→decode）全部 0 差异，但**还没有它们的真机样本**，遇到认不出的图请把样本发来。

【这是什么】
一个常驻右下角托盘的小工具，能双向处理「ue隐图」的混淆图：
· 丢进去一张混淆图 → 自动解码，输出「原名_解码.png」
· 丢进去一张普通图 → 自动混淆，输出「原名_mixed_密码.png」
算法与「ue隐图」网页离线版 v1.2 逐行一致（V2 / V3 都支持，编码解码都一致）。
纯本地运行：不联网、不下载、不安装、不上传、不统计任何东西。

【怎么用（三步）】
1. 双击 ue隐图.exe —— 直接打开「ue隐图 面板」（窗口标题栏就是它的名字）。
2. 把图片拖进面板上的虚线框（也可以点虚线框选文件，一次可以拖很多张）。
3. 处理完在面板下方出现缩略图卡片，输出文件就在原图旁边。

面板第 1 行的「读取并监视这个文件夹」开关打开后，你往那个文件夹里丢图也会自动处理，
不用每次拖 —— 这就是原来的"监视文件夹"功能，开关即权限。

【自动识别规则】
· 有色块条（底部 34 格，红头蓝尾）→ 一定是混淆图 → 解码
· 没有色块条：先按当前密码试解一遍，解出来的画面明显更平滑就认定是混淆图 → 解码
· 都不成立 → 当普通图 → 混淆
所以同一个框里混着放混淆图和普通图也没关系，不会弄错。

【QQ / 微信 里的图怎么递进来（全局热键）】
1. 在 QQ / 微信 里对图片点右键 →「复制图片」（复制的是图片文件也行）。
2. 按 Ctrl+Alt+M（默认热键）。

   · 底部三个按钮：另存为… / 复制到剪贴板 / 关闭；**只有你自己点「复制到剪贴板」结果才会进剪贴板**
   · 窗口一出现就会抢焦点，就算你下意识按 Ctrl+V，也粘不到群里
   · 同时会存一份到 %APPDATA%\ueyintu\history\（历史记录里能看到），设了监视文件夹也会在那里存一份
· 剪贴板里没图 → 提示「剪贴板里没有图片」
· 剪贴板支持两种形态：直接复制的图片、以及复制的图片文件（png/jpg/jpeg/webp）
· 改热键有三个入口：① 面板「高级选项」展开后那一行「全局热键 Ctrl+Alt+M ［修改…］」
  ② 托盘右键 →「设置热键…」 ③ 面板收起时按钮下面那行小字也会告诉你当前热键。

  · 字母和数字要配合 Ctrl / Alt / Shift（否则会把正常打字全吃掉）

  · 下面的胶囊可以直接点：小键盘 1~9、小键盘 0、小键盘 + - * /、小键盘 回车、F8/F9/F12、

  · **如果这个组合被别的程序占用，程序会在启动时自动换一个能用的**（候选顺序：

· 不记得热键也没关系：面板上有「处理剪贴板里的图」按钮，托盘菜单里也有同一项。

【输出文件命名规则】
· 解码：原名_解码.png
· 混淆：原名_mixed_<密码>.png（没设密码时密码位置写 0100）
· 统一存成 PNG，写到原图同一个目录，原图不动、不删、不覆盖
· 只认 .png .jpg .jpeg .webp；其它后缀直接忽略
· 已经有「_解码」结尾的文件不会被重新解码（避免自己解自己）

【只写"看出来是解对了"的图】
解码时不会无脑写文件：解码后画面必须明显更平滑（平滑度比值 ratio < 0.75）才写盘。
不达标就只弹一次气泡「xxx 解不出来（可能不是这套算法）」，不生成文件。

【开机自启怎么取消】
方法一：面板里把「开机自启」开关关掉（或托盘菜单里把它关掉）。
方法二：Win+R → regedit →
        HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
        删掉右边的 ueYintu 这一项。

【不联网」和防火墙规则怎么处理】
面板里把「不联网」开关关掉（或托盘菜单 →「网络安全」→「恢复联网」），
会删除「ue隐图-禁止联网-出」和「ue隐图-禁止联网-入」这两条防火墙规则 ——
删的只是系统规则，程序本身没有联网代码，永远上不了网。
也可以在「高级安全 Windows Defender 防火墙」里手动删这两条规则。
注意：面板上这个开关是按「当前这个 exe 的完整路径」判定的 —— 如果你把 exe 移到别的位置改名，
旧规则绑的是旧路径，面板会显示「规则指向别的路径」而不是「已写入防火墙」，
这时把开关关掉再打开一次，就会用新路径重建规则（也可能要你在防火墙里手动删掉旧的）。

【怎么彻底关掉它】
面板右上角 ✕ —— 默认是"关窗口＝退出程序"（连文件夹监视一起停）；
想让它在托盘常驻，把「关闭窗口后仍在右下角托盘运行」开关打开，之后 ✕ 才缩到托盘。
然后右键托盘图标 →「退出」。程序不会偷偷留后台。

【配置存在哪】
%APPDATA%\ueyintu\config.json（历史备份在同目录的 history 子文件夹）
包含 folder（监视文件夹）、password（密码）、paused（是否暂停）、autostart（开机自启）、
closeToTray（关窗口是否缩托盘）、hotkey（全局热键，默认 Ctrl+Alt+M）、viewerBlur（看图窗口默认是否模糊，默认 true）。删掉这个文件＝恢复默认。

【命令行（给自动化用，完全不弹窗）】
  ue隐图.exe --decode <输入图> <输出图> [密码]
      解码并写到输出路径。退出码 0 = 成功，1 = 解不出来 / 判据不过（不写文件）。
  ue隐图.exe --encode <输入图> <输出图> [密码] [v3|v2]
      混淆并写到输出路径（默认 V3）。退出码 0 = 成功。
  ue隐图.exe --selftest <输入图> <参考图> [密码]
      解码后与参考图逐像素比对，打印 DIFF=<不同字节数>；完全相同返回 0。
      不给密码时会自动试一遍（V3 试 step 01~99，V2 再叠加补边 0~3）猜一个。
  ue隐图.exe --auto <输入图> [密码] [v3|v2]
      同面板拖拽：自动判断该解码还是该混淆，输出到原图同目录。
  ue隐图.exe --clip [输出png] [密码]
      处理剪贴板里的图：只写文件（不弹窗、也绝不碰剪贴板），同时进历史备份。
      不给输出路径时写到 %TEMP%\ue_clip_<时间戳>.png。
      退出码 0 = 成功，1 = 剪贴板里没有图 / 处理失败。
  ue隐图.exe --shot <输出png>
      把面板截一张图后立刻退出（作者用来检查界面，普通用户用不到）。

【图标】
exe 里已经内嵌了图标：文件图标、托盘图标、面板标题栏左上角的小图标都从 exe 自己身上取，
你把 exe 单独拷到别处也照样有图标，不需要旁边放 .ico 文件。

【属性里能看到啥】
右键 ue隐图.exe → 属性 → 详细信息：
  文件说明   ue隐图
  产品名称   ue隐图
  公司       B站 UP 主 游动羽翼
  版权       作者：B站 UP 主 游动羽翼
  文件版本   2.3.0.0

【环境要求】
· 只支持 Windows（Win7 SP1 及以上，32 / 64 位都行）。
· 需要 .NET Framework 4.0 或更高版本 —— Windows 10 / 11 系统自带，不用额外安装。
· 单文件绿色程序，不联网、不写系统目录；可能写注册表/系统设置的地方只有两处，
  都是你自己点了开关才写：「开机自启」（HKCU\...\Run）和「不联网」（防火墙规则）。
